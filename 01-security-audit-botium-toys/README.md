
# Botium Toys — Internal Security Audit

## Project Overview

This project documents an internal security audit conducted for
Botium Toys, a fictional small business based in the United States.

The project was completed as part of my cybersecurity training to
practice security control assessment, risk identification,
compliance analysis, and security recommendations.

> **Disclaimer:** Botium Toys is a fictional organization used for
> educational purposes. This project does not represent an audit
> performed for a real company.

## Objective

The objective of the audit was to review the organization's existing
security posture, identify potential risks, threats, vulnerabilities,
and control gaps, and recommend improvements to better protect
critical assets and sensitive information.

## Frameworks & Security Principles

The audit considered:

- NIST Cybersecurity Framework (NIST CSF)
- CIA Triad
- OWASP security principles
- PCI DSS
- GDPR
- SOC considerations

## Key Findings

The assessment identified several security gaps, including:

- Lack of least-privilege access
- Lack of separation of duties
- No intrusion detection system (IDS)
- No disaster recovery plan
- No backups of critical data
- Lack of encryption for sensitive information
- Weak password requirements
- No centralized password management system
- No regular schedule for legacy-system maintenance

## Existing Security Controls

Existing controls identified during the assessment included:

- Firewall
- Antivirus software
- Data-integrity controls
- Physical locks
- CCTV surveillance
- Fire detection and prevention systems
- Privacy policies and procedures
- 72-hour breach notification planning for EU customers

## Recommendations

The audit recommended implementing or improving controls such as:

- Least-privilege access
- Separation of duties
- Encryption
- Intrusion detection
- Disaster recovery planning
- Critical-data backups
- Stronger password policies
- Centralized password management
- Regular legacy-system maintenance
- Proper asset classification
