# Nmap & Zenmap — Network Port Scanning

## Overview

This project documents my hands-on practice using Nmap and Zenmap to explore network discovery, port scanning, service identification, and network exposure in an authorized/controlled environment.

## Objectives

- Perform network port scanning
- Identify open, closed, and filtered ports
- Identify services running on discovered ports
- Explore service/version detection
- Explore operating system detection
- Understand network exposure and attack surface
- Relate scan findings to network security considerations

## Tools Used

- Nmap
- Zenmap

## Practical Exercise

During this exercise, I used Nmap/Zenmap to perform network scanning within an authorized environment.

The exercise helped me understand how network scanning can reveal information about exposed services and potential attack surfaces.

## Key Findings

The scan provided information about:

- Open ports
- Closed ports
- Filtered ports
- Discovered services
- Service/version information
- Operating system information where detectable

## Security Relevance

Network scanning can help security professionals understand what services are exposed within an environment and identify areas that may require further security review.

Unnecessary or improperly secured services can increase an organization's attack surface.

## Security and Ethics

All scanning activities documented in this project were performed in an authorized/controlled environment for educational purposes.
